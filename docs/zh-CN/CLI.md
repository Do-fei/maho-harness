# CLI 设计与行为

English: [`../en/CLI.md`](../en/CLI.md)

CLI 使用克制的单列布局：一次只呈现一个决定，状态标签明确，不依赖颜色、Emoji、动画或特定字体。

完整帆船只出现在首次引导和安装回执中，日常命令保持紧凑和机器可读。

```text
                 |
             |\  |\
             | \ | \
             |  \|  \
             |   |   \
             |___|____\
                 |
           ______|_______
       ~~~\_____________/~~~

              M A H O
 Model-Agnostic Harness for Outcomes
          Proof before done.
```

## 交互合同

- `maho init` 默认 dry-run。
- `--apply` 只修改缺失路径。
- 非交互应用必须提供 `--yes`。
- `--json` 返回确定性的机器可读输出。
- `--locale en|zh-CN` 选择终端文本和安装的 Skill 语言。
- `--no-color` 面向禁止 ANSI 输出的脚本和终端。Beta 界面目前不输出 ANSI 序列也能完整阅读。
- `--agent all` 只选择七个已验证客户端。
- 实验性适配器必须按名称显式选择；回执会将其标为“实验性”，并提示尚无真实客户端验收。

每份回执都报告已验证与实验性选择、已创建、已保留、已跳过、已覆盖、验证状态和下一条命令。状态始终使用文字表达，绝不只依赖颜色。
