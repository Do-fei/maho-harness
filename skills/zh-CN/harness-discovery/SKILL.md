# MAHO 发现

用于新仓库、陌生技术栈，或支持命令与变更边界不明确的情况。

1. 运行 `maho discover <project>`。
2. 检查 Git 状态、现有 `AGENTS.md`、README、构建元数据和建议检查。
3. 运行 `maho readiness <project>`。
4. 启用 MAHO 时，先运行不带 `--apply` 的 `maho init` 并审阅预览。
5. 只在解析后的仓库边界内应用，绝不覆盖现有规范。
6. 分开报告检测到的事实、未知项、建议命令和就绪度发现。

成功标准：仓库具有可审阅的发现与就绪度证据，并且任何推测出的命令都没有被冒充为已执行。
