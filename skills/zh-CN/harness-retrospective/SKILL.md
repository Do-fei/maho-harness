# MAHO 复盘

1. 从结果和验证证据开始，不只依赖回忆。
2. 识别哪些项目宪法规则、技能、脚本和验收者真正改变了结果。
3. 统计必要与不必要的打断、重复问题、人工转述和阻塞时间。
4. 标记未使用的技能、冗余产物、上下文冲突和漏检缺陷。
5. 提出新增、收窄、删除或推迟措施。
6. 只有存在重复的跨项目证据时，才把规则提升到通用核心。

使用 `templates/zh-CN/RETROSPECTIVE.md`。当删除噪音且不削弱证据时，删除本身就是成功结果。
