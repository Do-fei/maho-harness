# 独立验收

仅当全新验收者可能改变重大验收决定时使用。

1. 接收规格、验收标准、最终产物和已有证据。
2. 不接收或复述实现者的私有理由和结论。
3. 默认只读权限。
4. 攻击隐藏情况、信任边界、测试投机和用户可见行为。
5. 从不变量推导负面案例；相关时覆盖相邻值、前缀或易混淆值、编码、缺失状态、别名和符号链接边界，不能只测试新增分支。
6. 将“保持当前行为”视为兼容性约束，而不是保留违反安全不变量行为的许可。
7. 保存准确命令或观察，以及预期与实际结果。
8. 使用 `templates/zh-CN/INDEPENDENT_VALIDATION.md` 返回 `PASS`、`FAIL` 或 `INCONCLUSIVE`。
9. 记录共享模型、共享测试和不可用证据等限制。

自检有价值，但绝不能标记为独立验收。
